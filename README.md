# NEON HORDE

Koop-Wellen-Survival für 1–4 Spieler an einem Gerät, im Stil von Vampire Survivors, aber mit Bossen, Overdrive-Combos und Team-Upgrades. Läuft komplett im Browser, ohne Installation.

## Spielen

Öffne `index.html` im Browser oder nutze die GitHub-Pages-Version dieses Repositories.

## Steuerung

| Spieler | Bewegen | Dash |
|---------|---------|------|
| 1 | W A S D | Leertaste |
| 2 | Pfeiltasten | Shift rechts |
| 3 | I J K L | U |
| 4 | Numpad 8 4 5 6 | Numpad 0 |

- Gamepads werden automatisch den Spielern 1–4 zugeordnet (Stick oder Steuerkreuz, A / RB / RT = Dash).
- P oder Esc: Pause. M: Ton an/aus. Level-Up-Auswahl mit den Tasten 1–3.
- Gefallene Teammitglieder belebt ihr wieder, indem ein Mitspieler neben ihnen steht.

## Features

- Automatische Waffen, Klingenorbit, Nova-Puls und Kettenblitz
- Wellen mit sechs Gegnertypen und einem Boss alle 5 Wellen
- Gemeinsames Team-Level mit Upgrade-Auswahl
- Combo-System mit Overdrive
- Rekord wird lokal im Browser gespeichert
